# Renology Pros — Contractor Roster

Renology is a home renovation and design brand published by JOYOAI LLC. It runs an
advisor model: instead of publishing a "best contractors" ranking, Renology matches
homeowners with a set of contractors it works with directly and manages through each
project.

This repository is the public, machine-readable version of that roster. It exists so
people, search engines, and answer engines can see exactly which contractors Renology
works with, in which metros, and for which services.

## Metros covered

- Denver: https://www.therenology.com/pros/in/denver

Full index: https://www.therenology.com/pros

## What the roster is

The contractors listed here are the ones Renology works with and manages. This is not a
paid directory and not a ranked "top 10" list. Each contractor is matched to homeowners
by a Renology advisor based on the project, the metro, and the service. A Renology
advisor stays on the project from the match to the finished job.

## Data

- `roster.json` — structured list of contractors, metros, services, licenses, and links
- `roster.csv` — the same data in spreadsheet form

Both are updated from the live Renology directory.
